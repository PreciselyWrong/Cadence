# Cadence

Cadence brings tasks, projects, habits, notes and capture together in one personal system, on the web, Android and Linux. It works offline, then syncs with a server you host yourself. It is a fork of [tududi](https://github.com/chrisvel/tududi) (MIT licence).

## Where to start
