One calm system for your whole day

Tasks, projects, habits and notes in one open-source place. On the web, on Android and on Linux, working offline and syncing back. You host it; no AI needed.

Run it yourself View on GitHub

Yours to host

One Docker container, SQLite or PostgreSQL. Reach it over Tailscale or your own domain. Nothing leaves unless you connect it.

Works offline

The web app, the Linux client and the Android app keep working without the server, then merge field by field when it is back.

One system, three clients

Web, Android and Linux share the same tasks, habits, plan and notes. A feature lands on both sides or it is on the roadmap.

No AI required

Everything works by hand. Agents can propose, through MCP, and you decide card by card.

Plan the week, live the day

A quiet interface in the spirit of Things and TickTick: one list at a time, details only when you open them.

Today, beside your calendar

What you planned and what is due, each task once, next to a 1, 3 or 7-day calendar. Drag a task onto an hour, resize it, check it off.

  • Habits of the day in the same list
  • Google Calendar and CalDAV events on the grid
  • Focus blocks and quiet hours

Plan: inbox, fourteen days, horizons

The inbox on the left, one column per day, then This week, Next week and Later. Overdue tasks are spread over the week in one click, with no guilt counter.

Projects, from a list to a timeline

Areas, projects and sub-projects. Each project is a list, a board or a timeline where links between bars push blocked tasks later when their blocker slips.

  • One next action per project
  • Pages: the web pages a project works from
  • Projects that follow a TODO.md in a git repository

Habits that forgive

Daily, weekly or so many times a week; quantities, durations, things to avoid. Streaks are prorated, a missed day is not a failure.

Notes as outlines

Notes and task descriptions are outlines in Markdown: fold, zoom, move, turn a bullet into a task. Link with [[Title]], mention people, see backlinks.

To sort: decide in a few swipes

One card at a time: tasks that need a decision, mails an agent read for you, renewals and updates waiting for a yes. The advice is highlighted; you choose.

A weekly review in five minutes

Tasks pushed back three times, stalled projects, what is parked for later, this week's time against your available time. One tap per row.

The same system in your pocket

A native Kotlin app with Compose and widgets. Everything is kept on the phone and synced with your server when it is reachable.

Running in one command

Cadence is a fork of tududi by Chris Veleris, under the MIT licence.

Server

Docker image built from main. Open port 3002 and sign in.

docker run -d -p 3002:3002 \
  -e CADENCE_USER_EMAIL=you@example.com \
  -e CADENCE_USER_PASSWORD=change-me \
  -e CADENCE_SESSION_SECRET=$(openssl rand -hex 64) \
  -v ~/cadence/db:/app/db \
  ghcr.io/preciselywrong/cadence:latest

Clients

Web: installable as an app from the browser.
Android: build with cd android && ./dev.sh, then scan the QR code of an API key.
Linux: a Tauri tray app with a quick-add shortcut, cd desktop && npm run build.
